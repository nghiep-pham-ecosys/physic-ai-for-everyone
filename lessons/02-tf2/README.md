# Lesson 02: Coordinate frames and TF2

[English](#english) · [Tiếng Việt](#tiếng-việt)

## English

**Objectives:** explain a rigid transform; compose transforms by hand; name the REP-105 frames; publish static and dynamic transforms; look up a transform; inspect the TF tree.

**Run it** inside the devcontainer:

```bash
just lesson 02
```

The command builds the workspace, starts `frames.launch.py`, then checks the frame tree, a static transform, a moving transform and a lookup. It prints `PASS: lesson 02`, or stops with an error.

The full lesson is on the website under Lessons. See [exercises.md](exercises.md) and [solutions.md](solutions.md).

## Tiếng Việt

**Mục tiêu:** giải thích phép biến đổi cứng; ghép các phép biến đổi bằng tay; nêu các frame theo REP-105; phát transform tĩnh và động; tra cứu transform; xem cây TF.

**Chạy** trong devcontainer:

```bash
just lesson 02
```

Lệnh này build workspace, khởi động `frames.launch.py`, rồi kiểm tra cây frame, một transform tĩnh, một transform động và một lần tra cứu. Lệnh in ra `PASS: lesson 02`, hoặc dừng lại và báo lỗi.

Toàn bộ bài học nằm trên website, mục Bài học. Xem [exercises.md](exercises.md) và [solutions.md](solutions.md).
