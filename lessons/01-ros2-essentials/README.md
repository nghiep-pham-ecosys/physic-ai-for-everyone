# Lesson 01: ROS 2 essentials

[English](#english) · [Tiếng Việt](#tiếng-việt)

## English

**Objectives:** explain nodes, topics, services and parameters; build a workspace with colcon; write a publisher and a subscriber in Python; start them with a launch file; test them headless.

**Run it** inside the devcontainer:

```bash
just lesson 01
```

The command builds the workspace, starts the launch file, then checks the nodes, the topic, a parameter and a service. It prints `PASS: lesson 01`, or stops with an error.

The full lesson is on the website under Lessons. The code is in `ros2_ws/src/pai_basics`. See [exercises.md](exercises.md) for practice and [solutions.md](solutions.md) for answers.

## Tiếng Việt

**Mục tiêu:** giải thích node, topic, service và parameter; build workspace bằng colcon; viết publisher và subscriber bằng Python; khởi động bằng launch file; kiểm thử không cần GUI.

**Chạy** trong devcontainer:

```bash
just lesson 01
```

Lệnh này build workspace, khởi động launch file, rồi kiểm tra node, topic, parameter và service. Lệnh in ra `PASS: lesson 01`, hoặc dừng lại và báo lỗi.

Toàn bộ bài học nằm trên website, mục Bài học. Code ở `ros2_ws/src/pai_basics`. Xem [exercises.md](exercises.md) để luyện tập và [solutions.md](solutions.md) để đối chiếu.
