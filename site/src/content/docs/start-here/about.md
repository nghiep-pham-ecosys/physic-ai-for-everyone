Physical AI for Everyone is a complete, open-source Physical AI project that anyone can learn from: theory, hands-on practice, simulation, open code and open infrastructure.

The project grows a single robot, `pai_bot`, lesson by lesson, instead of many disconnected examples. It is built on ROS 2 Jazzy and Gazebo Harmonic, and every lesson must pass headless, so a GUI is a bonus and never a requirement.

## Principles

- **Evidence first.** A lesson is done only when it has merged code, a passing CI run, a simulation video or GIF, and a lesson page.
- **Know before proposing.** Unverified numbers are never invented. They are marked OPEN, with a note on what needs checking.
- **Built on established knowledge.** Every technical claim cites official documentation, a book or a paper.
- **Run it before publishing it.** Nothing is published until the maintainer has run it and can explain it.
- **Original work.** The robot, its worlds and the content are designed from scratch for this project.
